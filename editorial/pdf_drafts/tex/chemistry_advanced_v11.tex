\subsubsection*{UC-ADV11-P132 · Brusselator开放反应体系的稳态唯一性、复特征值与Hopf临界}
\noindent\textbf{题目}\par
某理想开放化学振荡模型采用无量纲Brusselator方程dx/dτ=A−(B+1)x+x²y、dy/dτ=Bx−x²y，其中x、y为非负浓度标度，τ为无量纲时间，A=1.200、B=2.700为恒定外部供给参数。求全部正稳态(x*,y*)，推导二维Jacobian矩阵及其迹、行列式、两个复特征值实部和正虚部，判断局部线性稳定性。进一步将B视为可调参数，求Hopf临界B\_H、临界角频率和临界小振荡周期；在保持A=1.200、改为B=2.400时求迹和稳定螺旋的频率。要求验证解唯一、正象限边界不向负浓度流动、Jacobian谱与物理条件，并解释为何开放体系不能对x+y直接使用封闭反应器的质量守恒和为何线性失稳本身不证明存在稳定极限环。\par
\medskip\noindent\textbf{分步解答}
\begin{enumerate}
\item 由dy/dτ=Bx−x²y=x(B−xy)=0，正稳态须满足xy=B，故y=B/x。
\item 代回dx/dτ=A−(B+1)x+x²(B/x)=A−x，得到唯一正稳态x*=A=1.200、y*=B/A=2.250。
\item 在通用(x,y)处Jacobian为J=[[−(B+1)+2xy, x²],[B−2xy,−x²]]。
\item 利用稳态xy=B，J*=[[B−1,A²],[−B,−A²]]=[[1.700,1.440],[−2.700,−1.440]]。
\item 迹Tr=B−1−A²=0.2600；行列式Det=A²=1.4400，行列式与B无关且为正。
\item 特征方程λ\_e²−Tr λ\_e+Det=0，因Tr²−4Det<0，得到实部Tr/2=0.1300、正虚部√(Det−Tr²/4)=1.192937551。
\item 实部为正，故在B=2.700时稳态为局部不稳定螺旋；线性化不能单独证明非线性极限环的存在与稳定性。
\item 当Tr=0时临界B\_H=1+A²=2.4400，特征值±iA，因此Hopf临界角频率ω\_H=A=1.2000（每无量纲时间）。
\item 临界线性周期T\_H=2π/ω\_H=5.235987756个τ单位，非物理秒数，除非另指定缩放。
\item 在B=2.400时Tr=−0.0400、Det=1.4400，特征值−0.0200±i1.199833322，是稳定螺旋。
\item 在x=0边界有dx/dτ=A>0，在y=0边界有dy/dτ=Bx≥0，非负象限正向不被穿出；稳态浓度均正。
\item 这是由外部供给和移除维持的开放体系，d(x+y)/dτ=A−x≠0，不得假设x+y守恒；有限分子数、热效应或速率常数变化时模型需要改写。
\end{enumerate}
