### UC-ADV5-I20　热激发Frenkel空位—间隙对的自洽浓度与形成焓

**题目**

在具有等数目可占据正常阳离子位和间隙位的假想AB晶体中，Frenkel缺陷对的平衡为A_A⇌V_A+A_i；定义同一标准位点分数x为每种缺陷的分数，空位生成对的理想平衡常数K=x²/(1−x)。900 K时测得x=0.002000，缺陷对形成焓ΔH=+40.00 kJ/mol且视为常数。求900 K的K、1100 K的K及x、缺陷密度相对增量，并证明自洽正根唯一。不能在计算中忽略正常位占据率1−x却又声称精确。

**严格推导与解答**

1. 每个Frenkel对产生一个正常位空位与一个间隙离子，因此[V]=[A_i]=x，正常位占据1−x。

2. 900K的质量作用常数为K1=x1²/(1−x1)=0.000004008016032。

3. van’t Hoff关系ln(K2/K1)=−ΔH/R(1/T2−1/T1)，代入得1100K常数K2=0.00001059300823。

4. 由x2²=K2(1−x2)，得x²+K2 x−K2=0，唯一正根x2=[−K2+√(K2²+4K2)]/2=0.003249397995。

5. 缺陷分数相对增长x2/x1=1.624698997；因为ΔH>0，升温使正向缺陷生成有利。

6. 函数x²/(1−x)对0<x<1严格递增，从0增至∞，所以求得的正根唯一，而另一二次根为负。

7. 数值逆核验：按独立化学计量、平衡和约束关系复算，三个无量纲检验残差分别为 3.198e-16、0.000e+0、0.000e+0；满足题定理想模型，但不代表专家审定。

**最终答案**：K900 = 0.000004008016032 dimensionless；K1100 = 0.00001059300823 dimensionless；x1100 = 0.003249397995 site fraction；relative = 1.624698997 ratio。

**模型边界**：理想稀缺Frenkel位点对，缺陷无聚集且两个子晶格标准态一致，形成焓常数。

**逆向核验**：3 组科学方程或守恒式；最大无量纲数值残差 3.198e-16。专家审核未完成。

### UC-ADV5-I21　三价金属二聚水解的单体—二聚体分布反演

**题目**

一份100.0mL酸性水样中假想三价金属以单核M3+及二核M2(OH)2^4+形式存在。条件二聚反应为2M3++2H2O ⇌ M2(OH)2^4++2H+，pH由强缓冲固定，已将H+效应吸收到K_cond=[dimer]/[M3+]²=450 L/mol。金属元素总分析浓度CM=0.01200M（以单个M原子计），无沉淀和其它物种。求单体、二聚体浓度、二聚金属原子比例、单体与二聚物摩尔数及二聚程度随K增大方向。

**严格推导与解答**

1. 设二聚体的分子浓度x；总金属元素浓度C=[M3+]+2[dimer]，所以[M3+]=C−2x。

2. 质量作用关系x=K(C−2x)²，物理区间0<x<C/2。

3. 在该区间x/(C−2x)²严格递增，所以物理解唯一，可用二分法求x=0.00443102554 M。

4. 游离单体浓度m=0.00313794892 M，二聚体浓度d=0.00443102554 M，注意一个二聚体贡献两个M原子。

5. 二聚金属原子分数2d/C=0.7385042567，100mL水样单体mol=0.000313794892、二聚体分子mol=0.000443102554。

6. 增加K使方程左侧的目标值增大，由单调性可知x增大；不能把dimer浓度直接当作总金属分析浓度。

7. 数值逆核验：按独立化学计量、平衡和约束关系复算，三个无量纲检验残差分别为 2.220e-16、0.000e+0、0.000e+0；满足题定理想模型，但不代表专家审定。

**最终答案**：monomer = 0.00313794892 mol/L；dimer = 0.00443102554 mol/L；atom_fraction = 0.7385042567 fraction；dimer_mol = 0.000443102554 mol。

**模型边界**：条件形成常数已包含固定pH与水的活度，二核形式只作为假想二聚模型，忽略真实多核水解的竞争。

### UC-ADV5-I22　配体质子化与单核配位的竞争质子账本

在pH=9.000的外部缓冲水溶液中，一元单负配体L−的共轭酸HL满足pKa=8.000。假想三价金属M3+总浓度0.003000M，仅形成ML2+，条件形成常数对游离L−给β=10^3.2 L/mol。游离酸碱池[HL]+[L−]与络合消耗的L之和为L总=0.01200M。求自由L−、HL、游离M3+、ML2+和束缚配体占比；给出唯一根证明并核验全部配体和金属守恒。

2. 配位平衡给[ML2+]=βl[M3+]；金属元素守恒CM=[M3+]+[ML2+]，由此[M3+]=CM/(1+βl)。

4. 左侧在l≥0严格单调递增，且l=0时为0，l=CL时大于CL，故在(0,CL)有且仅有一个正根。

5. 代入β=10^3.2求l=0.008372934728 mol/L，HL=0.0008372934728 mol/L。

6. 平衡游离M3+=0.0002102282011 mol/L，络合ML2+=0.002789771799 mol/L；总金属浓度m+ML=0.003 mol/L。

7. 配体束缚比例ML/CL=0.2324809832；核查l+HL+ML=0.012 mol/L等于0.01200。

**最终答案**：L_free = 0.008372934728 mol/L；HL = 0.0008372934728 mol/L；M_free = 0.0002102282011 mol/L；ML = 0.002789771799 mol/L；ligand_bound_fraction = 0.2324809832 fraction。

**模型边界**：缓冲固定pH=9，只有HL、L−、M3+与一配体ML2+四种指定物种；忽略其它酸碱及配位形态。

6. 初始A+为0时模型的浓度型Nernst电势因lnQ发散，真实体系需活度与成核约束；能量应积分E(ξ)dQ而不是固定EξF。

**最终答案**：xi = 0.03484848485 mol；Aplus = 0.03484848485 mol；Bplus = 0.01515151515 mol；charge = 3362.367634 C。

**模型边界**：一电子假想金属交换，无离子迁移过电位与活度修正，明确不能以Q=0推断真实无穷电势。

### UC-ADV5-I28　混合价铁氧化物的电荷补偿与穆斯堡尔双谱线占比

**最终答案**：FeII = 0.4 atoms/formula；FeIII = 1.6 atoms/formula；fractionFeII = 0.2 fraction；meanFe = 2.8 valence。

**模型边界**：题设Li填隙且Fe仅有II、III；真实LiδFe2O3的结构稳定性不予声称。

**逆向核验**：3 组科学方程或守恒式；最大无量纲数值残差 8.882e-16。专家审核未完成。
