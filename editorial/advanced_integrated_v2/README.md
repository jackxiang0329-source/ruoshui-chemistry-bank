## 后续每轮 200 的执行标准

200 是**上限性目标**，不是允许牺牲解题准确性凑数的硬指标。只有满足以下条件的新题才计入高阶原创数量：具有独立的科学模型与完整情境；包含至少两种耦合约束（例如非线性平衡、能量守恒、动力学、物料守恒、误差约束等）；列出关键推导和解的物理区间；完成可独立重复的数值或符号逆向核验；无与已入库高级母题的语义实质重复。单纯参数变化、新增一个套算小问、不同方法的机械排列，不计为新的高级题型。

本批 **12 份均为机器审核中的原创题文**：`awaiting_expert_review`、`publishable=false`，专业化学审定 0，正式组卷资格 0。来源独创性和版权复核与科学复核仍须分别进行。
