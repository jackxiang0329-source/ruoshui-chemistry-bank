# 已拉取化学开源数据 · 隔离区

本目录由用户要求，将核实了上游 BSD-3-Clause / MIT 仓库许可声明的真实数据拉取后去重，**不是正式可发布题库，也不保证原题中的第三方内容已获得单独再授权**。

- `chemiq/`：814 道唯一英文基准题，原题和答案保留，标记 `benchmark_quarantine`；建议不用于训练/出题模型，以免污染盲测。
- `chemquiz/`：273 条化合物英文名→分子式练习候选，标记 `external_quarantine`；另有四份供核查的基础数据。
- `licenses/`：上游仓库许可证原文，必须保留其署名与免责声明。
- `registry.json`：已导入与未导入项目及其原因。
- `REPORT.md`：源文件版本、去重规则、数量与局限。

本仓库的正式公开清单只由 `scripts/export-manifest.mjs` 生成，**不读取本目录**。导入区与公开 API 必须隔离。
