# 大学化学 · 高阶综合题批次库（待专家复核）

此目录用于**原创高阶综合习题及逐步中文解答**的成批归档；它既不是自动采集原题区，也不是 `release/` 正式组卷题库。现有大规模 `data/candidates/` 中的参数变式、学习卡和外部研究隔离素材，**不得与这里的题量重复统计**。

## 命名及结构

- 数据目录：`data/integrated_challenges/YYYY-MM-DD/batch-NNN.jsonl`，每批使用一个 UTF-8 JSONL 文件，每行恰好一道完整题。**不要每题生成独立散乱 JSON、PDF 或 TeX 文件。**
- 统一题号：`UC-CI-YYYYMMDD-NNN`，不重新编号旧题。每条含题干、分步中文解答、数值答案、方法标签、验证信息、难度和专家审核状态。
- 批次校验程序：`node scripts/check-integrated-challenges.mjs`。正式发布审批仍走仓库现有 `harvest/publication_approvals.json` 与 `release/chemistry-approved-manifest.json` 审核闸门。
- 独立原创题目文本及作者原创解答按记录声明 CC0 1.0；不改变仓库中任何外部资料的既有许可证。

## 质量和未完成事项

当前完成的是**机器级结构、组合去重、逆算、应用公式与守恒检查**。由于测量路径与下游模型交叉组合，完整的教学合理性、实验可行性、物理化学近似程度、答案精度、中文排版和深层语义去重仍须人工逐题审核。在审核前，所有记录保持：

```json
{"quality_status":"awaiting_expert_review","publishable":false,"exclude_from_official_bank":true}
```

不要因本批新增200条便把旧候选库存量、正式可出卷题量或“已独立专家审核”统计直接增加200。后续批次应优先引入新的**独立母题与不同学科耦合**，严禁仅调参数再复制本批。
